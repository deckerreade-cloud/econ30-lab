This concept defines the operating workflow for this project knowledge base:
read new source files from `knowledge-base/raw/`, write one summary per source,
extract concepts into one-concept-per-file articles, add backlinks across
related concepts, and keep `knowledge-base/wiki/index.md` updated after every
change.

The workflow prioritizes integrating information into existing concept articles
instead of creating near-duplicates.
