# Rehearsal checklist — Econ 30 presentation

**Target:** 7:30 out loud (30 sec buffer)  
**Site:** https://econ30-lab.vercel.app/  
**Slides:** https://econ30-lab.vercel.app/presentation  

---

## Before presentation day

### Browser prep
- [ ] Open capstone site; scroll to Page 2 once so charts load
- [ ] Confirm **Compare all** is pressed (default on load)
- [ ] Open `/presentation` in second tab
- [ ] Zoom 100–110%; full screen or clean window for share
- [ ] Close notifications; quit Slack/email
- [ ] Test screen share on the machine you’ll use in class

### Full run (use timer)
- [ ] Slide 1–2 → site Page 1 → question → data → dashboard demo → Page 3
- [ ] Total time ≤ **8:00** (aim for 7:30)
- [ ] Demo block (Compare all → Rent → SF) ≤ **2:30**

### Friend / family test
Ask after your run:

1. “What was my research question?”  
   **Expected:** Who wins and loses when office values crash?

2. “What’s one thing you’ll remember?”  
   **Expected (any of):** SF crisis vs national headline; Manhattan split / K-shape; workers vs capital; Compare all shows SF diverges

If they can’t answer both, **cut motivation** and **lengthen demo + takeaways**.

### Backup path (no Wi‑Fi or broken charts)
- [ ] Can you present using **slides only** for 5 minutes?
- [ ] Slide 4 has static vacancy chart + site URL
- [ ] You can read winners/losers from script without scrolling

### Mobile (optional)
- [ ] Open site on phone — readable? buttons work?

---

## Day-of (5 minutes before)

- [ ] Tabs: (1) `/presentation` (2) econ30-lab.vercel.app scrolled to dashboard
- [ ] Water; phone on silent
- [ ] Script: `presentation/walkthrough-script.md` on phone or printed one-pager

## Cut list (if running long)

1. Skip FRED panel entirely  
2. Skip case study cards — only winners/losers  
3. Shorten data beat to one sentence + Slide 4  
4. Keep: question, Compare all demo, thesis line, one limit  

---

## Memorable lines (repeat twice)

**Question:** Who wins and loses when office values crash?

**Thesis:** National “office crisis” headlines hide a San Francisco crisis — and a Manhattan split.
