# Office CRE scrollytelling site

Static HTML/CSS/JS narrative with D3 charts and Scrollama.

## Run locally

**Recommended** — from the project root (so `../data/` in modules and `../knowledge-base/` source links both work):

```bash
cd "/path/to/Lab Project"
python3 -m http.server 8080
```

Open `http://localhost:8080/site/`.

**Alternate** — from `site/` only (data loads; wiki links in Sources may 404):

```bash
cd site
python3 -m http.server 8080
```

Open `http://localhost:8080`.

Source links in the story use `../knowledge-base/...`. Serve the **repository root** (parent of `site/`) so those paths resolve, e.g. `python3 -m http.server 8080` from `Lab Project/` and open `http://localhost:8080/site/`. Alternatively run from `site/` only if you do not need wiki/PDF links to work.

Do not open `index.html` as a `file://` URL — ES modules and `fetch()` need HTTP.

## Data

- `data/curated.json` — headline stats and citations (edit by hand).
- `data/timeseries.json` — generated by `python code/export_timeseries.py` from `data/cleaned/city_panel_enriched.csv` after `python code/run_pipeline.py`.

## Dependencies (runtime)

- D3 and chart code load via `import` from jsDelivr inside `js/charts.js`.
- Scrollama loads from unpkg in `index.html` (global `window.scrollama`).
